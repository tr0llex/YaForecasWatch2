# Редизайн под Pebble Time 2 (emery) — план работ

Область: только платформа **emery** (200×228, 64 цвета, тач, RGB-подсветка, пульсометр).
Остальные платформы не ломаем намеренно, но и не оптимизируем.

Тестовая конфигурация (зашита в `fixtures/moscow-current.json`, включается автоматически
в `tools/pebble-shot.sh`): Москва, Цельсий, 24 часа, неделя с понедельника,
производственный календарь РФ.

---

## Дизайн-ревью текущего состояния

Проведено по скриншоту эмулятора emery, увеличенному ×3.

### Баги вёрстки (видимые дефекты)

| # | Проблема | Где |
|---|---|---|
| B1 | Подписи левой оси графика (`16`, `12`) наезжают друг на друга, читаются как каша | `forecast_layer.c` |
| B2 | Подписи правой оси UV обрезаны краем экрана, тики выходят за пределы | `forecast_layer.c` |
| B3 | Город (`Moscow`) обрезан сверху — неверная базовая линия | `weather_status_layer.c` |
| B4 | Время события солнца (`3:44`) обрезано сверху — та же причина | `weather_status_layer.c` |
| B5 | Цифры второго ряда календаря подрезаны сверху и снизу: ряд 22px при шрифте 22px | `calendar_layer.c` |
| B6 | Подсветка «сегодня» обрезает глиф снизу | `calendar_layer.c` |

### Проблемы композиции

| # | Проблема |
|---|---|
| C1 | «Июнь 2026» — самый статичный элемент экрана, а по весу второй после часов |
| C2 | Пустые провалы над и под часами (~20px), при том что графику места не хватает |
| C3 | Область графика ~44px — три ряда данных (температура, осадки, UV) в ней сливаются |

- [x] **T6.3** Строка статуса показывает дату («чт, 18 июня») — раньше её нёс календарь
- [x] **T6.4** Светлая тема циферблата (`appendix/theme.c`), переключатель в настройках
- [x] **T6.5** `tools/shot-themes.sh` — съёмка обеих тем одним прогоном
- [x] **T6.6** Русская плюрализация шагов (шаг / шага / шагов)
- [ ] **T6.7** Провал ~20px между датой и часами: часы центрируются в своей полосе,
      оптический отступ великоват

Найдено и исправлено по ходу итераций:

| Что | Причина |
|---|---|
| Светлая тема не применялась | Фон окна красится один раз при загрузке, до прихода настроек |
| Дата и шаги исчезали | Слои перечитывали цвет, фон — нет: чёрное на чёрном |
| Чёрная плашка под осью графика | `GColorBlack` захардкожен |
| Пропадали подписи часов и стрелка заката | Захардкожен `GColorWhite` |
| Подписи часов подрезаны снизу | `BOTTOM_AXIS_H` 10px при шрифте 16px |
| «…» вместо «10» на оси UV | Ширина поля 19px мала для двух цифр |
| Плашка «сегодня» высотой 94px | Сетка делила всю высоту экрана на 2 ряда |
| Заголовок месяца наезжал на дни недели | `HEADER_H` меньше суммы двух строк |
| Тема «залипала» между прогонами | Эмулятор сохранял настройки; добавлен `pebble wipe` |
